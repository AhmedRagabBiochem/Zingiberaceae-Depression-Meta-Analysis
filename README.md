 # Zingiberaceae Against Depression: A Systematic Review and Meta-Analysis

## Overview

This repository contains the analysis materials for a systematic review and meta-analysis investigating the effects of *Curcuma longa* (curcumin/turmeric) and *Zingiber officinale* (ginger) on depression and depressive symptoms.

## Research Focus

The project evaluates the potential effects of:

- *Curcuma longa* (Curcumin/Turmeric)
- *Zingiber officinale* (Ginger)

## Repository Contents

### Manuscript

The manuscript associated with the systematic review and meta-analysis.

### Figures

The repository includes:

- Curcumin subgroup forest plot
- Curcumin subgroup funnel plot
- Ginger subgroup forest plot
- Ginger subgroup funnel plot
- Risk of bias summary
- Risk of bias graph

## Methodology

The systematic review and meta-analysis followed a structured systematic-review methodology and PRISMA-based reporting framework.
